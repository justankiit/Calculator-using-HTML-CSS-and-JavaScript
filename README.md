## Usage

To run the project, follow these steps:

1. Clone or download the repository to your local machine.
2. Open the `index.html` file in any modern web browser (e.g., Chrome, Firefox, Edge).
3. Interact with the calculator by clicking the buttons to perform basic arithmetic operations.

Enjoy using the updated calculator UI!
